    What runs where
    
      
      
        
    • HTML / JS — a whole project (HTML, CSS, JS, images, sounds) previews live in a sandboxed frame. Nothing leaves your browser.
      • 
        
    • Python · Play — real Python (Pyodide/WebAssembly) running in your browser, drawing to a canvas. Great for animated games.
      • 
        
    • C++ · Play — clang compiles your program to WebAssembly in the browser (first use downloads the ~28 MB compiler once) and runs it against the same canvas API. Needs Chrome 137+.
      • 
        
    • Console mode (Python, Java, C++) — compiled and run by the free Judge0 service. Type input lines under the output to play text games; each line re-runs the program with everything typed so far, so keep programs deterministic (fixed secrets, seeded random) for the transcript to line up.
      • 
      
    

      
    Bringing in a game
    
      
      
        
    • Open ▾ → Import from GitHub URL — paste a repo link (public repos only, e.g. a JS canvas game). Every file is downloaded straight into a new project.
      • 
        
    • Import .zip — GitHub's "Download ZIP" works as-is.
      • 
        
    • Or drag a folder from the Files app onto the editor.
      • 
        
    • Asset paths like img.src = "img/bird.png" resolve to the files in your project. Paths built at runtime work too, as long as the final string matches a project file.
      • 
      
    

      
    Python Play API (import runline as rl)
    
      
    Define setup() (optional) and update(dt) — called every frame with the elapsed seconds.
    
      
    
        
    rl.set_size(w, h)canvas size (call in setup)
    
        
    rl.width() / rl.height()current size
    
        
    rl.clear(color)fill the whole canvas
    
        
    rl.rect(x, y, w, h, color)filled rectangle
    
        
    rl.stroke_rect(x, y, w, h, color, width)outlined rectangle
    
        
    rl.circle(x, y, r, color)filled circle
    
        
    rl.line(x1, y1, x2, y2, color, width)line
    
        
    rl.text(x, y, s, color, size, align)text; align = "left" | "center" | "right"
    
        
    rl.key_down("ArrowLeft")True while held (uses KeyboardEvent.code: "Space", "KeyA", "ArrowUp"…)
    
        
    rl.key_pressed("Space")True only on the frame the key went down
    
        
    rl.mouse_x() / rl.mouse_y()pointer position in canvas pixels
    
        
    rl.mouse_down() / rl.mouse_pressed()held / just clicked (also works with touch)
    
        
    rl.beep(freq, ms)a simple tone
    
        
    rl.stop()end the game loop
    
      
    
      
    Colors are CSS colors: "red", "#3498db", "rgba(0,0,0,0.5)". print() output appears under the canvas.
    

      
    C++ Play API (#include "runline.h")
    
      
    Same functions in the rl:: namespace — rl::set_size, rl::clear, rl::rect, rl::stroke_rect, rl::circle, rl::line, rl::text, rl::key_down, rl::key_pressed, rl::mouse_x/y, rl::mouse_down/pressed, rl::beep, rl::time(). Write main() as a loop and call double dt = rl::next_frame(); once per iteration — it waits for the next animation frame. printf/std::cout output appears under the canvas. C++20 with the full standard library; exceptions are not supported.
